自动坐标对齐与 LiDAR 状态

让机器人在同一平地静止，扫描共同墙面、柱子等环境。以参考狗当前的位置为原点、朝向为 +X，自动匹配选中机器的点云；检查预览后应用。不会移动机器人。

点云默认关闭。查看地图、恢复标定或自动对齐前，请开启所需设备（包括参考狗）的点云；完成后可关闭。连接健康在设备列表查看。

任意摆放：仅选择参与机器和参考狗，无需填写左右顺序、间距或朝向。参考狗自动加入；每台分别与参考狗的共同环境匹配。整个过程不驱动机器人。

参考坐标固定在采集时参考狗的位置（0,0）和朝向（+X），不会跟着它移动。只有地面、单墙或对称环境时可能无法确定位置，失败与歧义均不会自动通过。

对齐需要新鲜定位和重叠点云，采集到应用期间请保持全部机器静止。先核对预览中的 X、Y、朝向和墙面重合，再应用；匹配失败显示红色候选，不代表已定位。应用会替换全部旧标定、清除旧回位起点，未通过设备保持未标定。

自动列队

横队按当前位置保留左右顺序，其余队形按编号分配位置；需要先完成 map frame 标定，执行时按实时 map_pose 闭环修正。

以选中编号最小者的当前位置和朝向为基准生成目标。横队保留当前左右顺序，队形中心位于该基准位置，两台都可能移动；间距为相邻目标中心的距离。

目标位置闭环编排

坐标使用已标定的 map frame，单位米；yaw 使用弧度。全体稳定到位后进入下一段。

先勾选机器人，再读取当前位置生成模板。模板不会移动机器人；修改目标后再执行。每段需包含相同编号。可添加 duration（秒）启用共同时间进度；timeout 要留出到位修正时间。路线距离检查仅覆盖参与机器，不包含障碍物和未参与设备。

编号实际位置 / 朝向目标位置 / 朝向误差速度指令（机身坐标）到位

速度列为发送的控制指令，并非实测速度。暂停编排后请检查位置再重新执行；此版本不保证与音乐定时同步，也不自动绕障。
